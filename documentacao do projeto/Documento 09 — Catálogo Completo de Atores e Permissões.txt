Documento 09 - Atores, Papéis e Modelo de Permissões (RBAC)

Versão: 1.0

Status: Oficial

1. Objetivo

Este documento define todos os atores do iHostPro, seus papéis (Roles), permissões, responsabilidades e limitações.

O objetivo é garantir que:

cada usuário visualize apenas o que lhe compete;
toda ação seja autorizada antes de executada;
a plataforma seja preparada para crescimento futuro;
novos perfis possam ser adicionados sem alteração estrutural do sistema.

O sistema deverá utilizar RBAC (Role Based Access Control).

As permissões deverão ser independentes do código de interface.

2. Conceitos

22. Segurança

Nenhuma permissão poderá ser validada exclusivamente na interface.

Toda validação deverá ocorrer obrigatoriamente no backend.

A interface deverá apenas ocultar funcionalidades sem acesso.

23. Objetivos

O modelo de permissões deverá:

garantir segurança;
permitir escalabilidade;
facilitar manutenção;
reduzir riscos;
suportar crescimento da plataforma;
permitir novos perfis sem alterações estruturais.
24. Considerações específicas para o iHostPro

Embora o sistema utilize RBAC como base, recomenda-se que a autorização seja implementada como RBAC + ABAC (Attribute-Based Access Control).

Exemplos de atributos que poderão influenciar uma autorização:

o utilizador pertence ao mesmo tenant;
o proprietário está associado ao imóvel;
a faxineira foi designada para aquela faxina;
a reserva pertence ao imóvel consultado;
a política do tenant permite determinada ação.

Essa combinação oferece muito mais flexibilidade para um SaaS multi-tenant do que um RBAC puro, mantendo simplicidade para o utilizador final.
